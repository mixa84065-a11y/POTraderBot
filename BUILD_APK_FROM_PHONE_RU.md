# Как получить APK с телефона (облачная сборка)

В этом архиве есть GitHub Actions workflow для сборки APK под Android 16 (API 36).

1. Войдите на github.com в браузере телефона или создайте аккаунт.
2. Создайте новый репозиторий, например `POTraderBot`.
3. Загрузите в репозиторий ВСЕ файлы и папки из этого проекта, включая скрытую папку `.github/workflows`.
4. Вкладка **Actions** → разрешите запуск workflows, если GitHub попросит.
5. Запустите **Build Android APK** через **Run workflow** (или дождитесь сборки после загрузки в ветку main).
6. Откройте завершённый запуск workflow и скачайте артефакт `PO-Trader-Bot-debug-APK`.
7. Распакуйте скачанный ZIP на телефоне и установите `app-debug.apk`. Android может попросить разрешить установку из этого источника.

Важно:
- Это debug APK для тестирования, не публикационная подписанная сборка.
- Прототип пока использует синтетические свечи; к Pocket Option он не подключается и сделки не размещает.
- Не загружайте в репозиторий пароли, cookies, токены или другие данные аккаунта.
