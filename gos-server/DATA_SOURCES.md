# GoS: источники данных
Alpha23: локальная SQLite-база до 50 000 завершённых футбольных матчей, уникальный fixture ID API-SPORTS.IO. Сохраняются идентификаторы, дата, итоговый счёт и доступный счёт первого тайма. Источник выбирается в карточке: API или локальный архив. Архив обновляется при загрузке календаря и архивных дат, не запускает дополнительных запросов сам. Локальный анализ отделён от журнала основной модели.

Следующие адаптеры (ещё не реализованы):
- SStats: https://api.sstats.net/docs/ и https://sstats.net/api — документированный публичный API с ограничениями анонимного доступа. Проверить разрешение и покрытие, формат ответа и сопоставление команд/лиг.
- API-SPORT.RU: https://docs.api-sport.ru/ — отдельная авторизация, тариф и идентификаторы.
Не объединять ID разных поставщиков, не передавать ключи между ними. Не обещать полноту исторической базы до теста источника.
