# GoS: независимое аналитическое ядро

Первый этап серверной архитектуры. Чистый модуль ECMAScript, без зависимости от Android, базы данных, торговых функций и API-SPORTS. Не развёрнут как HTTP-сервис.

Вход: два объекта home/away, поля n, gf, ga, htN, htFor, htAgainst (числа завершённых матчей, суммы голов). Допускаются до 20 матчей, минимум 5 для расчёта; для первого тайма минимум 5 наблюдений отдельно. Источник обязан исключать матчи после времени начала анализируемой встречи.

Выход: версия модели, объём выборок, вероятности исходов и голов (доли 0–1), null при отсутствии статистики первого тайма. Модель независимого Пуассона, не калибрована, не учитывает составы и силу лиг.

Проверка: node --test gos-server/model.test.mjs

Следующий этап: отдельный авторизованный HTTP-интерфейс, ограничение частоты вызовов, сравнение с Android-реализацией и явный выбор локального/серверного расчёта. Не передавать API-SPORTS ключ, торговые ключи или персональные данные. Для журнала фиксировать версию модели, время и исходные агрегаты.
