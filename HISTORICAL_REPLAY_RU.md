# Историческая проверка (исследовательский режим)

Независимая проверка текущего Android spot-анализатора, не серверного Bybit worker. Никаких заявок, API-ключей или доступа к счёту. Не является доказательством доходности.

CSV с заголовком `timestamp_ms,open,close,turnover24h`: завершённые минутные свечи по одному инструменту, в UTC, строго по возрастанию, оборот известен на момент закрытия свечи. Источник, период и качество данных нужно фиксировать отдельно. Не подставлять будущий оборот.

Из корня проекта (JDK 17):

```sh
mkdir -p build/replay
javac -encoding UTF-8 -d build/replay src/main/java/com/potraderbot/MarketStrategyEngine.java src/main/java/com/potraderbot/HistoricalSpotReplay.java src/main/java/com/potraderbot/ResearchTrendFilter.java
java -cp build/replay com.potraderbot.HistoricalSpotReplay history.csv 240 5 8 6 2
```

Аргументы: история, число свечей для сигнала, горизонт удержания в минутах, полный спред в bps, комиссия за сторону в bps, проскальзывание за сторону в bps. Числа примера — допущения, а не подтверждённые тарифы. Вход на открытии следующей свечи, выход через заданный горизонт; нет заглядывания в будущие свечи при принятии решения. Разрывы исключаются. Базовый сценарий покупает на каждом таком же непересекающемся окне. Доходность с условным реинвестированием, просадка только по закрытым сделкам. Нет моделирования стопов, частичных исполнений, ликвидности объёма и внутрисвечной просадки. Не смешивать результаты с серверной статистикой.

Для сравнения версий использовать неизменённый набор котировок, одинаковые издержки и отдельный период проверки, который не участвовал в подборе параметров.

## Экспериментальный фильтр 5m/15m

Для сравнения исходного сигнала и варианта с подтверждением тренда требуется lookback не менее 240 минут. Используются только полностью закрытые UTC-бакеты. Фильтр требует восходящего тренда на обоих масштабах, разделения EMA5/EMA13 не менее 0,05% и эффективности движения за 10 интервалов не ниже 0,30. Это заранее выбранные исследовательские пороги, не оптимизированные и не подтверждённые рынком. Отчёт отдельно показывает сопоставимые окна, отсутствие данных, отказы из-за флэта/противоречия и результаты обеих версий на одинаковых окнах. Серверный робот и основной Android-анализатор не изменены. Параметры не подбирать на контрольном периоде.
