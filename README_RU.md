# GOD OF TRADING — Android prototype

## Текущий функционал проекта
- Нативный Android-проект на Java.
- Существующий экран и оформление не менялись.
- Технический анализ EMA 9/21 и RSI 14.
- Отдельный data-only контур для ручной торговли на Binarium.
- Загрузка минутных OHLC-свечей через Twelve Data.
- Загрузка экономического календаря Investing.com через независимый посредник API.SH.
- Фильтр новостного риска: высокий импакт — пауза за 30 минут до и 30 минут после события; средний — за 15 минут до и после.
- Проверка минимального количества свечей, порядка времени, OHLC и свежести котировок.
- Сигнал WAIT при отсутствии данных, устаревших котировках или новостном риске.

## Источники данных и ключи
1. Twelve Data: нужен личный API key для минутных Forex OHLC. Документация: https://twelvedata.com/docs
2. API.SH: нужен API key для календаря Investing.com. Это не официальный API Investing.com: посредник возвращает общедоступные данные сайта в JSON. Документация: https://api.sh/docs/investing-economic-calendar

Ключи передаются конструкторам клиентов во время запуска. Не добавляйте реальные ключи в Git, исходники или сообщения. Для постоянного использования потребуется безопасное локальное хранение или серверный прокси; APK можно исследовать, поэтому клиентский ключ нельзя считать полностью секретным.

## Важные ограничения текущей ветки
- Новые data-клиенты и анализатор добавлены, но ещё не подключены к существующему экрану MainActivity.
- Для реальных запросов нужны оба API key.
- Код этой ветки ещё не собран на Android SDK и не проверен на устройстве.
- Нельзя считать сигнал подтверждением прибыльности или гарантией результата.
- Приложение не входит в Binarium, не читает его экран и не открывает сделки. Сделки вводятся и подтверждаются вручную.
- Источник котировок Twelve Data может отличаться от цены/котировки Binarium; перед использованием нужно сравнить время и цены на одинаковом инструменте.
