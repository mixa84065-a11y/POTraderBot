# PO Trader Bot — Android prototype 0.1.0

## Что уже есть
- Нативный Android-проект на Java.
- Экран статуса и конфигурации стратегии.
- Анализатор EMA 9/21 и RSI 14.
- Правило сигнала CALL / PUT / WAIT.
- Каркас торгового движка и ограничители риска.
- Явное разделение между анализом и исполнением.

## Важные ограничения
- Кнопка анализа использует синтетические тестовые свечи, а не реальные котировки.
- Проект НЕ подключается к Pocket Option.
- Проект НЕ считывает экран официального приложения.
- Проект НЕ открывает сделки и не использует логин, пароль, cookies или токены.
- Показанный сигнал на синтетических данных не является торговой рекомендацией и не доказывает прибыльность стратегии.

## Как открыть
1. Установить Android Studio на компьютер.
2. Распаковать архив.
3. Открыть папку POTraderBot в Android Studio.
4. Дождаться синхронизации Gradle.
5. Запустить приложение на Android-эмуляторе или подключённом телефоне.
