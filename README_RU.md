# GOD OF TRADING — Android prototype

## Что входит в ветку обновления 0.2.0
- Ручной запуск анализа кнопкой — непрерывной трансляции нет, чтобы экономить API-запросы.
- Источник минутных OHLC-свечей: Twelve Data.
- Экономический календарь: API.SH (посредник данных календаря Investing.com, не официальный API Investing.com).
- Технический анализ EMA 9/21 + RSI 14.
- Фильтр новостного риска: high — 30 минут до/после; medium — 15 минут до/после.
- Проверка количества, порядка, OHLC и свежести свечей.
- При ошибке источника, устаревших данных или новостном риске приложение выдаёт WAIT/ошибку вместо сигнала.
- Приложение не авторизуется в Binarium и не размещает сделки. Входы остаются ручными.
- Экран и базовая компоновка сохранены; изменены только подписи и результат анализа.

## Защищённое хранение API-ключей (версия 0.3.0)
- Ключи Twelve Data и API.SH вводятся в приложении через «НАСТРОИТЬ API-КЛЮЧИ».
- Ключи сохраняются в EncryptedSharedPreferences с ключом шифрования, защищённым Android Keystore.
- Обычное закрытие приложения и перезагрузка телефона не удаляют ключи.
- Ключи не встраиваются в APK через BuildConfig и не передаются в GitHub Actions.
- Хранилище локальное для каждого телефона. При удалении приложения данные хранилища могут быть удалены Android; для переноса на другой телефон ключи нужно ввести там отдельно.
- Выход из будущего Google-аккаунта не должен автоматически удалять локальные API-ключи; очистка выполняется отдельным действием пользователя.
- Не вставляй API-ключи в GitHub, чат или публичные файлы.

## Google-вход и обмен сигналами
Для реального Google OAuth и двустороннего обмена между телефонами нужен отдельный Supabase-проект: URL проекта, публичный anon/publishable key и настройка Google OAuth в Supabase/Google Cloud. Эти значения ещё не настроены в репозитории, поэтому вход через Google и синхронизация сигналов пока не активированы.
SQL-схема с профилями, связями пользователей и сигналами находится в `supabase/migrations/202611100001_shared_signals.sql`. В ней включены Row Level Security политики: пользователь видит только свои связи и сигналы, а отправлять сигналы можно только принятому контакту.

## Структура Android-проекта
- `app/` — настоящий Android application module.
- `app/src/main/java/com/potraderbot/` — Java-код приложения и data engine.
- `app/src/main/AndroidManifest.xml` — разрешение на интернет.
- `app/build.gradle` — конфигурация приложения и зависимостей защищённого хранилища.

## Важные ограничения и проверка
- Ветка подготовлена для ручного анализа пары EUR/USD с минутными свечами.
- Источник Twelve Data может отличаться от цены Binarium. Перед любым решением сравни котировку и время свечи на самой платформе.
- Календарь и котировки запрашиваются только после нажатия кнопки.
- Реальные API-ответы и поведение на устройстве ещё требуют проверки с личными ключами.
- Нельзя считать сигналы гарантией результата; сначала тестируй на демо/бумажном режиме.

## Сборка
Проект использует Android Gradle Plugin 8.9.1, Gradle 8.11.1 и JDK 17. Для сборки APK через GitHub Actions открой вкладку Actions и запусти workflow **Build Android APK** на ветке `feature/binarium-data-engine`.
