# GOD OF TRADING — Android app

## Обновление 0.6.3
- Ручной запуск анализа: API-запросы выполняются только по нажатию кнопки.
- Источник минутных OHLC-свечей: Twelve Data; временные метки запрашиваются явно в UTC.
- Экономический календарь Investing.com: через API.SH (независимый посредник, не официальный API Investing.com).
- Многофакторный анализ: EMA, RSI, MACD, ATR, ADX proxy, Bollinger, структура, свечные модели и сценарии.
- Фильтр новостного риска: high — 30 минут до/после; medium — 15 минут до/после.
- Проверка количества, порядка, OHLC и свежести свечей.
- При ошибке источника, устаревших данных или новостном риске приложение выдаёт WAIT/ошибку вместо сигнала.
- Приложение не авторизуется в Binarium/Pocket Option и не размещает сделки. Входы остаются ручными.

## Защищённое хранение API-ключей
- Ключи Twelve Data и API.SH вводятся в приложении через «НАСТРОИТЬ API-КЛЮЧИ».
- Ключи сохраняются в EncryptedSharedPreferences с ключом шифрования, защищённым Android Keystore.
- Ключи не встраиваются в APK и не передаются в GitHub Actions.
- Хранилище локальное для каждого телефона. После переустановки приложения ключи может потребоваться ввести заново.
- Не вставляй API-ключи в GitHub, чат или публичные файлы.

## Google-вход и обмен сигналами
SQL-схема для будущих аккаунтов и двустороннего обмена сигналами находится в `supabase/migrations/202611100001_shared_signals.sql`. Сам вход и синхронизация пока не активированы: нужны отдельный Supabase-проект, URL, публичный anon/publishable key и настройка Google OAuth.

## Важные ограничения
- Ветка подготовлена для ручного анализа EUR/USD с минутными свечами.
- Источник Twelve Data может отличаться от котировки Binarium/Pocket Option. Сверяй цену и время последней свечи на самой платформе.
- API-календарь и котировки запрашиваются только после нажатия кнопки.
- Сценарные оценки — эвристические баллы, а не откалиброванные вероятности и не гарантия результата.
- Перед реальными решениями сначала тестируй на демо/бумажном режиме.

## Сборка
Проект использует Android Gradle Plugin 8.9.1, Gradle 8.11.1 и JDK 17. Workflow **Build Android APK** запускается при изменениях ветки `feature/binarium-data-engine`.
