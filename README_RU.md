# GOD OF TRADING — Android trading assistant

## Что добавлено
- Отдельный Android-модуль приложения.
- Получение закрытых минутных OHLC-свечей через Twelve Data.
- Анализ EMA 9/21 и RSI 14 (Wilder).
- Сигналы CALL / PUT / WAIT с пояснением и временем последней свечи.
- Проверка корректности свечей и сетевые тайм-ауты.
- Разрешение INTERNET и сборка APK через GitHub Actions.

## Запуск
1. Откройте репозиторий в Android Studio или GitHub Codespaces.
2. Синхронизируйте Gradle.
3. Соберите задачу :app:assembleDebug или запустите приложение на телефоне.
4. В приложении укажите пару, например EUR/USD, и личный API-ключ Twelve Data.
5. Нажмите «Загрузить котировки и анализировать».

API-ключ вводится в поле приложения, не записывается в исходники и не коммитится. Запросы идут к Twelve Data по HTTPS. Бесплатный тариф поставщика может ограничивать частоту/объём запросов; доступность минутных данных зависит от тарифа и инструмента.

## Ограничения и безопасность
- Приложение не подключается к аккаунтам Pocket Option или Binarium.
- Не считывает экран брокера и не размещает реальные сделки.
- CALL / PUT — только результаты технического фильтра, а не гарантия направления.
- Нет доказательства прибыльности. Перед любыми решениями нужна проверка на исторических данных и демо-счёте с учётом выплат, задержек и проскальзывания.
- Никогда не передавайте пароль брокера, cookies или токены.

## Параметры текущего фильтра
- Свечи: 1 минута, только закрытые.
- Экспирация для будущего бумажного тестирования: 3 минуты.
- EMA: 9 и 21.
- RSI: 14; зона CALL 50–68, зона PUT 32–50.
